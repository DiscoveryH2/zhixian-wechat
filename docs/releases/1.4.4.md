# 知弦 PC 1.4.4 预览版

这一版修复自动回复对微信窗口 OCR 的新消息判断。先前只靠右侧气泡序列重叠：用户滚动旧记录可能被误认为新来信；相反，图片、链接或消息太长导致预览不符时，系统会永久暂停。现在知弦在内存中跟踪微信左侧**当前选中会话**的最新摘要签名：只有摘要真的变化、右侧聊天尾部与其可核对，才考虑最新入站文字。滚动旧记录不会改变左侧摘要；无法核对的媒体或视口这一轮跳过并继续监听，不会据此按发送键。

自动发送仍只面向当前可见的白名单会话。Jev 会先独立判断现在是否值得回复，再做风险分析、草稿与候选排序；知弦进程发送前复核会话、最新来信、上一条上下文、摘要签名和空输入框，并附 `（以上内容为知弦生成）`。当前微信显示非白名单会话时，界面明确显示「等待允许会话」，不会误称正在对目标发送。发送进程的脱敏阶段日志留在本机 `data/send-audit.jsonl`。

## 验证状态

- 238 项本地 `unittest` 通过，另有 1 项环境性跳过；合成测试覆盖摘要变化、旧记录滚动、无重叠视口、链接/短句跳过、白名单会话切换和发送前摘要变化拒绝。
- 真实 Jev 接口此前已用合成对话验证回复与跳过两种 typed 判断；本版是否在真实微信独立发送，仍必须以 `send-audit.jsonl` 中的知弦进程 `enter_called` 与微信对应发出气泡共同确认。仅见「运行中」或由 Codex 点击微信发送键，都不算这项验证。
- WeFlow 在本项目中提供只读会话和入站推送，不提供已验证的后台发件接口；本版不会自动切换到屏幕外的聊天。微信必须保持目标会话可见，窗口 OCR、群昵称和预览文字不确定时会跳过。
