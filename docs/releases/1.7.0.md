# 知弦 v1.7.0 跨平台客户沟通预览版

新增 macOS 工作台、客户行动中心与带原文证据的承诺扫描，向销售、客服和客户成功的跟进闭环推进。当前仍是技术预览，企业权限、加密聊天库、签名发行与商业授权服务的后续实施见 [商业化执行计划](https://github.com/DiscoveryH2/zhixian-wechat/blob/main/docs/COMMERCIAL_PLAN.md)。

- macOS 采用钥匙串保存 API Key，数据位于 Application Support；支持导入、归档检索、分析、媒体与朋友圈建议。Mac 原生微信数据库读取、窗口 OCR 和发送尚未适配。包按构建机架构生成，目前未配置 Developer ID 签名和公证。
- 客户承诺扫描只保留消息 ID 与原文节选匹配的提案；用户核对内容和时间后才保存到行动中心。行动保留证据、持久状态和版本冲突保护，不自动发送。
- 增加中文 trigram 正文索引、旧消息定位、导入后本机预热；独立会话弹窗按页加载，较长目录使用虚拟列表，保留姓名、群名和图片/语音摘要。
- 新增极光配色、约 4.4 秒的镜头推进开场、背景遮罩与动效开关；支持自选背景和字号，减少动态效果时自动简化。
- 支持 OpenAI 兼容 multipart 语音转写、本机系统语音朗读；视觉模型继续处理用户主动选择的图片原件。语音转写是 STT，朗读是 TTS，媒体占位不会被假装理解。
- 朋友圈分析按所选数据来源读取好友近期历史，并保留历史不可用提示；只提供点赞、评论和私聊建议。
- 修复 Agent 丢弃最新未知方向消息、把非文字占位改成文字、忽略 WeFlow 断线缓存状态的问题；未知会话类型也转为人工复核。
- 发布改为 Windows/macOS 两端测试、打包和自检均成功后发布预览包，发布任务单独拥有 contents:write。历史一次失败发生在 Release 403 权限，而非测试或打包失败。

本地回归使用 Linux、合成消息和本机模拟服务；两端原生构建结果以本次 GitHub Actions 记录为准。没有使用真实客户聊天调用外部模型，也没有把合成发送验证计为真实微信送达。图片和语音仍需要实际原件；朋友圈依赖主动提供内容或兼容数据源，不能从零散缓存猜出全量动态。
