# 知弦 PC v1.2.0

这一版把单窗口分析扩展为可选择会话的桌面工作台，并加入独立的朋友圈建议与媒体理解入口。

- 全局会话弹窗支持搜索、分来源筛选、分页和预览预热。可连接本机 WeFlow 服务浏览其会话目录，也可主动导入 CipherTalk/ChatLab JSON 或 JSONL 归档；断开服务时会明确标示当前仅覆盖已收集或已导入的数据。
- 历史消息按页加载，图片按需预览与识别，语音按需播放与转写。OpenRouter 配置可自动选择相应视觉及转写模型；Jev 仍负责结构化关系判断。不能读取的媒体会显示原因，绝不伪造识别结果。
- 朋友圈可使用可用的 WeFlow 帖子索引或手动提供动态，结合选定好友的聊天背景，给出点赞、评论、私聊或暂缓的建议。评论草稿只在适合公开评论时生成，不会自动执行社交操作。
- 增加约 4 秒可跳过的开场镜头、游戏感交互、夜色与纸感主题、字体大小和本机背景图片。
- 扩充数据源、密钥隔离、媒体协议和大批量归档回归测试；发行包继续通过源码、打包和离线诊断检查。

完整解压 Windows 便携包后运行 `Zhixian.exe`。基础判断只需填写 API Key、Base URL 和 Model name。**全量历史不会从微信窗口自动产生**：需要正在运行并已授权的本机 WeFlow 服务，或由你主动选择 ChatLab 导出文件。图片识别、联网语音转写会在你点击对应操作时把所选媒体发往配置的模型服务；TTS 配音尚未提供。发行包不包含个人配置、聊天记录或 API 密钥。

使用与隐私边界见 [README](../../README.md) 和 [隐私说明](../PRIVACY.md)。
