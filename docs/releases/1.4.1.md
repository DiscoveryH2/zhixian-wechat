# 知弦 PC 1.4.1 预览版

1.4.1 修复了一种可能的重复发送情形：一次性历史补回复现在也会拒绝实时自动回复已经见过的入站消息 ID。这样可以避免实时自动回复已处理消息、而窗口采集稍后又将同一条消息识别为待补回复时再发送一次。

## 功能范围

其余历史补回复范围沿用 [1.4.0 发行说明](1.4.0.md)：用户明确选择当前可见且在白名单内的会话；只评估最近一个尚未回应的入站回合；每次最多发送一条；不广播、不切换屏幕外会话。已知时间戳超过 7 天的消息会跳过；时间未知时，需要用户确认当前会话并通过更严格的 Jev 判断。群聊需要可靠的定向证据或明确提及用户在该群的显示名称，一般群聊讨论不会触发。发送还受二次 Jev 分析、风险和候选排序门控、固定披露后缀、当前会话与输入框核验、冷却/限额、一次性去重和失败不重试约束。

## 已知限制

OCR 可能误识别会话、发言人、时间或群聊提及。模型判断依赖有限上下文；当目标或送达状态不确定时，应停止并人工检查。此补丁只避免实时自动回复已记录的消息 ID 再被历史补回复使用，不能证明所有外部消息来源都提供稳定且唯一的 ID。
