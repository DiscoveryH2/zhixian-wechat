# 知弦 PC 1.3.0 预览版

1.3.0 增加受限的自动回复能力。它只适用于明确加入本机白名单的会话，并且每次启动都默认关闭；用户需要在当前运行中明确启用。此版本不提供主动发起对话、定时消息或群发。

## 自动回复范围

- 只响应新收到的纯文字消息；历史导入、旧消息、自发消息和重复事件不触发。
- 白名单逐项记录会话标题、ID 和会话类型。它们可能识别个人关系，应将本机 `data/auto-reply.json` 当作私有文件保管。该文件是明文，保存策略、白名单和去重状态，不保存聊天正文或回复草稿。
- 群聊默认要求可靠确认消息提及了当前用户。窗口 OCR 无法可靠判断 @ 提及；要对 OCR 群聊自动回复，必须明确选择“全部群消息”模式，并承担响应群内任意新消息的影响。
- 支持消息防抖、会话冷却时间、每小时和每日上限，以及暂停和紧急停止。紧急停止不能撤回已交给微信的消息。
- 自动回复不会切换到屏幕外会话，也不会调用 WeFlow 发送 API。只会尝试当前可见并重新核验的微信会话。
- Jev 必须明确给出“当前适合实质回复”的判断、低风险结果和排序完成的候选；缺少任一项就跳过。
- 发送前必须新鲜核验目标会话、最后一条来信和前一条可见上下文、输入框为空且聚焦，以及填入后的草稿与预期文本一致。已有草稿会保留并阻止发送；核验失败则停止。同名会话或 OCR 识别差异仍可能造成身份不确定，遇到不连续视口会暂停。
- 每条自动发送的回复末尾都会恰好附加 `（以上内容为知弦生成）`，已有的同一标记会先去重再添加一次。
- 自动草稿所需消息上下文会发送给已配置的模型服务。联系人笔记不用于自动草稿。请按模型服务商的数据规则评估聊天内容出网。

## 发送限制

自动发送需要将回复填入当前输入框并按 Enter。微信焦点变化、界面状态、剪贴板或输入法等因素可能影响结果。程序可以核对按键前的窗口和草稿，但不能证明微信服务器已接收或对方已收到消息。若发送结果无法确认，自动回复会暂停；先检查当前微信会话，避免重复发送。

自动回复功能有意采用失败即停止的策略，但界面自动化和 OCR 仍可能受微信版本、缩放比例、主题和布局变化影响。启用前请理解误识别或界面竞态的风险，并设置适当的白名单和发送上限。

## 验证状态

204 项本地自回归测试通过（含一项环境性跳过）；自动回复单元与控制器测试使用合成会话和模拟输入框。桌面桥接与便携版完成了合成输入诊断。本机已对用户指定会话做**只读**真机检查：会话标题、可见的来信上下文、空输入框与新鲜画面均能识别；没有因此发送测试消息。合成和只读检查不能证明按键发送或微信送达；真正的回复发送冒烟仍需要启用后的新入站测试文字，完成前不把它写成已验证成功。
