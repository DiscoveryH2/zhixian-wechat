# 知弦 PC v1.5.2 预览版

修复升级后的自动回复启动问题：旧版保存的 OCR 群聊或联系人名单使用标题生成的会话 ID。切换到数据库来源后，知弦现在会按名称和会话类型查找对应的数据库会话；只有唯一匹配时才把名单迁移成稳定的数据库 ID。遇到重名或缺失会话时会明确要求从数据库会话目录重新选择，避免发给错误对象。

数据库名单在应用重启后无需先打开会话目录，也能凭稳定 ID 重新核验并启动。当前 Windows 用户的真机配置检查确认 Jev Key、判断服务和回复生成服务均可用；导致按钮启动失败的是旧 OCR 名单。自动回复每次启动仍默认关闭，用户需检查名单、群聊规则及发送限额后在界面确认启用。

本版没有把模型判断为“不明确”的历史 @ 消息强行发出。真实正向自动发送验收仍待一条通过 Jev 判断、风险、目标和输入框核验的消息。数据库读取和自动发送的其余限制见 [1.5.1 发行说明](1.5.1.md)。
