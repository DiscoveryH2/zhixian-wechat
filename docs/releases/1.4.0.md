# 知弦 PC 1.4.0 预览版

1.4.0 预览版加入一次性历史补回复。它帮助用户从一段已有对话中判断是否遗漏了值得回复的来信，并至多发送一条回复。此功能只作用于用户主动选定的一个会话，不会扫描其他聊天。预览发布不代表真实发送已经验证成功；验证边界列在下文。

## 处理范围

- 用户必须明确选择当前屏幕上可见、且已加入白名单的会话。每次操作都重新核对窗口和会话；不会切换到屏幕外会话，也不会广播。
- 根据可见历史，只考虑最近一个尚未回应的入站消息回合。若之后已经有自己的回应，或没有明确待处理的入站回合，就跳过。一次操作最多发送一条。
- 若消息时间戳可确认且超过 7 天，跳过。若 OCR 无法确认时间，只有用户明确确认当前选中的会话仍需要处理，且 Jev 对目标和回复价值表现出更强把握，才继续评估。
- 群聊必须有可靠证据表明消息定向发给当前用户，或消息明确提及当前用户在该群的显示名称。普通群聊讨论、仅凭语气推测是在问用户，均不构成触发条件。
- 发送前重新运行 Jev 分析，并通过风险判断和候选排序门控。任何阶段未通过或状态不确定，都跳过发送。
- 保留每条自动发送回复的固定披露后缀 `（以上内容为知弦生成）`，以及现有的当前会话、最新消息、空且聚焦输入框和草稿核验。
- 继续受冷却、每小时/每日限额和一次性去重保护。结果不确定或失败时不自动重试；应先人工检查微信，避免重复发送。

## 隐私与模型请求

为判断历史回合，应用会把当前选中会话所需的消息上下文发送给配置的模型服务进行 Jev 分析、风险判断和候选排序。只选择一个会话不会将其他会话或整份本地归档上传。未知时间确认仅表示用户同意继续处理当前所选会话，不会扩大扫描范围。

## 验证状态

- 216 项本地 `unittest` 通过，另有 1 项环境性跳过。
- 桌面桥接合成冒烟通过。
- 真实 Jev typed 历史判断使用合成对话通过；此结果不代表真实聊天内容已提交。
- Windows 便携版 5 项离线自检通过；ZIP 含 3108 个文件，精确密钥扫描结果为 0。
- 真实个人历史补回复判定为 skip，未发送。
- 群聊中存在多个同名或相近目标，仍需用户消歧；未发送。
- 真实微信自动发送仍未验证。以上测试均不证明消息已送达。

## 已知限制

OCR 可能漏字或误判发言人、时间戳、会话标题和群聊提及。Jev 的意图及风险判断是有限上下文下的模型估计。自动化只能验证发送前的本机窗口状态，不能证明微信已接收或对方已收到消息。遇到上下文、身份或送达状态不确定时，应停止并人工检查。
