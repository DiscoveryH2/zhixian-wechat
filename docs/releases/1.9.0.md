# 1.9.0 · 后台自动回复与工作 Agent

微信只需登录（窗口可收在托盘），知弦从本机数据库读到新消息、判断并回复；Work Agent 回到界面，任意 OpenAI 兼容模型三项配置即可跑通全链路。

- 修复数据库来源的游标格式不一致：此前窗口不打开时，实时新消息几乎全部被跳过。
- 发送时排除微信 4.x 隐藏的 `Weixin` 工具窗，修复"无法唯一定位微信主窗口"必然失败；目标不在当前会话时用微信搜索切换，并以 OCR 标题严格核验，不一致即拒发；发送后收起窗口并还原原前台窗口。
- 群消息剥离 `wxid:` 发送者前缀，按消息 `<atuserlist>` 精确判断 @我；会话头先于消息行可见时重读而不丢消息。
- 单次采集错误或发送核验失败不再永久暂停，连续 3 次才暂停；未确认送达只记录不暂停（去重已落盘，不会重发）。跳过原因写明具体规则。
- 判断阶段新增 Chat Completions JSON 适配：模型名不含 `jev` 时，判断、起草、排序、分诊与 Work Agent 共用同一组 apikey / baseurl / modelname。
- Work Agent 恢复入口（工作 Agent / 会话巡检 / 模型设置），与会话分诊状态隔离；单次请求最长 120 秒，错误透传 HTTP 原因，不支持工具或图片时自动降级。
- macOS 可通过 CipherTalk mac 版已配置账号只读监听本机微信数据库；自动发送仍仅限 Windows，并在后端强制校验。

发送瞬间仍需短暂唤起微信窗口并获取焦点（微信不提供以本人身份发消息的官方后台接口）。本版本仍为技术预览。
