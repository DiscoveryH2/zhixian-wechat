# 1.8.0 · 历史洞察与数字分身预览

知弦新增群聊/联系人历史洞察、稳定身份关联、持久朋友圈和有来源记忆的数字分身，补齐最近一页聊天之外的数据链路。

- 联系人按平台、本人帐号、发送者 ID 关联私聊、共同群本人发言和朋友圈；未知身份不猜测，同名与不同帐号隔离。
- 完整本地索引计算发言分布、来源、时间与媒体覆盖；模型使用跨时间样本，输出带逐字原文引用的观察与下一步。
- Windows 本机历史分批只读索引、持久断点；朋友圈支持缓存 XML 文字或 JSON 导入，手动帖子持久保存。
- 数字分身支持陪伴、纪念、排练、来源记忆管理、本机朗读、历史保存和删除。按问题检索创建时完整历史，输入模型的上下文受限制；生成文本不回写事实记忆。
- 停用记忆清理旧模拟历史；删除或并发修改阻止晚到结果保存。分身始终标为 AI 模拟，没有微信发送工具。
- 归档媒体识别结果持久保存并标注不确定性；原始消息改变时失效。
- 项目协作目标、决定与检查点记入 PROJECT_MEMORY.md，AGENTS.md 引导恢复。

既有背景上传、外观/字体、4.4 秒开场、图片/语音工具和 Windows 受约束自动回复继续提供。Mac 使用导入/兼容来源；原生取钥、发送、语音复刻、任意微信媒体解码、加密档案、团队权限、Developer ID 公证和独立商业取钥方案尚未完成。本版本仍为技术预览。
