# 知弦 PC v1.5.1 预览版

知弦的本机数据库来源现在能在微信最小化或收至托盘时继续监听联系人和群聊。真机只读测试将微信最小化 42 秒，期间识别到 1 条新到达的群聊文字；没有调用截图或发送入口，结束后恢复了窗口状态。数据库扫描按页覆盖会话索引，避免只看最近一页。

群聊回复判断现在会从当前用户已有的 CipherTalk 账号配置取得本人显示名，并只把文字里明确 `@` 该称呼的消息标为指向自己。知弦会继续交给 Jev 决定是否值得回复。若 Jev 返回不明确、风险门槛未过或候选不可用，不会为了完成测试强行发言。本机测试群的新 @ 消息已通过数据库身份与定向检查；这轮 Jev 判断未达到回复门槛，因此一次性回复状态为跳过，**没有发送消息**。

发送路径可以在目标会话原本已打开、微信收在托盘或最小化时短暂恢复窗口，只裁切会话标题和输入框做核验，并在结束后恢复原有窗口状态。目标会话的消息正文、发言方向与最新消息 ID 仍来自本机只读数据库。知弦不会根据搜索结果猜测收件人，也不会自动切换到另一个聊天。

验证：合成测试覆盖隐藏窗口恢复、明确 @ 的身份匹配、数据库多会话调度和发送门控；真机验证了托盘中目标群的标题核验、数据库读取以及 Jev 跳过结果。尚未取得一次由知弦独立发送且在目标群数据库中确认的正向记录；这仍是预览版的验收边界。
