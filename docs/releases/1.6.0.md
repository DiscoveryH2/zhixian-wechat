# 知弦 PC v1.6.0 预览版

新增「知弦 Agent」：从会话目录明确选择最多三个联系人或群聊后，Agent 按需读取各会话最近一页，用有界的 Jev 判断流程给出“现在回复、稍后跟进、等待、无需动作或人工复核”的会话卡片。卡片展示所依据的真实消息 ID 与节选；判断足够明确时，可生成可复制的候选。工具步骤和停止原因在界面可查。

这是一轮**用户主动发起的只读巡检**。它不会自动观察整个微信账号、不会调用微信发送路径，也不会修改自动回复白名单；复制候选后仍由用户决定是否发送。图片、语音只有类型标签而没有实际文字时不会伪称理解其内容。一次最多三个会话、每个会话最多四十条近期消息；原始巡检结果只保存在本次应用内存中，不另建 Agent 聊天档案。

便携版请完整解压后运行 `Zhixian.exe`。本版通过合成回归、QtWebChannel 到隔离进程及本机模拟服务的端到端冒烟测试；另用两条**合成消息**接入已配置的 OpenRouter，确认 Jev typed 判断和三条候选能够返回。真实微信聊天没有用于这项模型测试。便携包自检和隐私检查通过后发布；实际微信自动发送仍沿用现有独立功能，**尚未取得可证明一次正向真实送达的完整记录**。Agent 的卡片是基于有限上下文的模型建议，不能代替用户核对事实和收件人。
