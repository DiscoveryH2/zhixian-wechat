# 知弦 PC v1.5.3 预览版

修复数据库自动回复在发送前被静止窗口画面误挡的问题。微信从托盘恢复后，画面不变时 Windows Graphics Capture 可能暂时没有新帧；旧版在 OCR 读完标题后才检查 1 秒时限，导致原本新鲜的画面刚过时限就被拒绝。知弦现在先核对时间，必要时重新建立采集，再核验目标群标题与输入框。

本机失败审计显示该次尝试只到 `blocked`，没有调用发送键。只读复现确认窗口标题匹配、输入框为空；修复后可到达粘贴前的输入框核验。后续若核验再次失败，自动回复页和脱敏审计会显示固定原因类别，不写入联系人、群名、聊天正文或候选回复。

本版已通过合成回归、便携包自检和隐私检查。**尚无一次由知弦独立发出并在目标群数据库中确认的正向真机记录**；发送结果不明确时不会自动重试。旧消息已消耗去重记录，更新后只处理重新启用自动回复后到达的新消息。
