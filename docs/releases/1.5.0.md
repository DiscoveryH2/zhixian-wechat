# 知弦 PC v1.5.0 预览版

本版把微信聊天正文的主要读取路线从可见窗口 OCR 扩展到本机加密数据库。若当前 Windows 用户已有 CipherTalk 账号配置，在设置里选择“本机微信数据库”即可按会话浏览微信 4.x 的本机历史并监听新消息；知弦无需另存微信数据库密钥。原有 OCR、WeFlow 和导入来源保留。

数据库读取使用 `sqlcipher3` 只读连接原始加密文件及 WAL，不调用 CipherTalk 附带的闭源、带授权校验的 DLL，也不生成明文镜像。会话列表按最近时间分页，先显示名称与最新摘要；选中会话才取有限消息页。压缩文字在本地解码，无法确认方向或解码失败的消息不会触发自动回复。图片和语音暂为占位，尚不代表可访问或理解媒体原件。

自动回复每次启动默认关闭，仍需明确设置白名单和群聊规则。数据库消息要经过新的入站基线、Jev 回复时机、风险/候选、冷却与限额门控，发送时固定附上 `（以上内容为知弦生成）`。当前发送能力仍只覆盖**微信窗口已显示且能唯一核验的目标会话**；知弦不会盲搜、切换到其他聊天或对同名目标猜测。发送前复核数据库最新入站消息 ID，只读取微信标题和输入框区域验证目标与草稿，按下发送键后尝试从同一数据库确认。若验证失败或结果不明，停止自动重试。

验证边界：合成自动化测试覆盖只读 SQLCipher、已提交 WAL 更新、跨分库消息映射、会话分页、方向识别、历史/新消息隔离及发送路由。本机实测确认原始加密数据库可只读打开、目录与消息页可读取，源程序和便携版均已在真实微信账号下进入数据库实时监听并完成 Jev 分析。真实窗口的错误目标测试在粘贴与发送前被拦截。**尚未把一次新的他人入站消息通过知弦独立发出并在目标会话数据库里确认**；在这一验收完成前，不应把自动发送理解为已通过真机验证。

隐私边界：程序不记录或上传微信数据库密钥，不把聊天截图作为数据库模式的正文来源。文字分析仍会把用户选择的上下文提交给其配置的模型服务。CipherTalk 原配置库、微信数据库及知弦可选的本地历史/导入文件都是私有数据，不能放进公开仓库或发行包。
