# 常见问题

## 找不到微信窗口

确认已经登录微信并打开具体聊天。微信进程存在，不代表聊天窗口可采集：隐藏到系统托盘、关闭主窗口或最小化后，可能没有可用画面。先从托盘重新打开窗口，再点击“单次读取”或重新开始观察。

初次排查建议使用普通主聊天窗口，放大到能够完整显示会话标题、聊天气泡和输入框。图片查看器、设置页和其他工具窗口不是聊天窗口。

如果仍然失败，请记录 Windows、微信和知弦版本、屏幕缩放比例，以及主窗口或独立会话窗口的情况。无需提供真实联系人名称或聊天截图。

## 识别不全、方向不对或消息重复

OCR 依赖当前窗口的像素和布局。窗口太小、气泡没有完整显示、主题差异、动画、特殊字体或微信更新，都可能影响识别。尝试放大窗口，等待画面稳定，再单次读取。

OCR 无法读取屏幕外的完整历史，也不会理解语音或图片里的实际含义。无重叠的滚动画面会被视为历史或不确定上下文，不应按新收到消息触发分析。可以把需要的文字手动粘贴到分析界面，并用 `我：` / `对方：` 标出发言方向。

## 模型连接失败

先核对服务商、API Key、Base URL 和模型名是否相互匹配，再点击“测试连接”。

| 现象 | 检查方向 |
| --- | --- |
| 未授权或 Key 无效 | 确认 Key 来自所填服务商，复制时没有多余字符，并且仍然有效 |
| 模型不存在或无权限 | 确认账号可以调用该模型；必要时修改模型配置 |
| 额度不足或限流 | 在服务商查看额度和调用限制，降低自动分析频率或稍后重试 |
| 判断接口格式不兼容 | 确认网关支持 Jev `decisions` / `systemone` typed answers 协议 |
| Jev 成功、回复生成失败 | 检查回复模型是否可用，以及高级回复配置是否完整 |
| 连接超时 | 检查本机网络能否访问配置的服务，排查防火墙或代理设置 |

OpenRouter 默认配置可以使用同一把 Key 完成判断和生成。TypeSafe 原生判断接口不生成候选，需要另配生成服务。不同来源的回复服务不会自动继承主 Key。

测试连接使用内置测试文字；不要为排查连接问题把真实聊天或 Key 发到 Issue。

## 能分析，但没有候选回复

界面的判断与回复分开处理。未配置生成服务、生成调用失败或响应无效时，仍可能看到有效的 Jev 判断；候选排序失败时也不会编造推荐分数。请查看界面提示，并检查高级回复设置。

## 无法填入微信

填入仅适用于与候选对应、且能够重新核验的当前微信会话。切换聊天、对话更新、标题识别失败、窗口失去焦点或画面过期，都会导致拒绝。

切回目标聊天，重新读取并分析后再尝试。如果仍不确定，使用“复制”，自行核对目标并粘贴。程序不会替你按 Enter 或点击发送；也不要把系统拒绝理解为需要打开自动发送功能。

## 换电脑后密钥无法读取

密钥使用 Windows DPAPI 保护，和 Windows 用户环境有关。复制便携目录后，可能需要在新电脑或新账户中重新填写 Key。笔记、联系人和可选历史是明文文件，请单独决定是否迁移。

## WeFlow 无法连接

WeFlow 是可选来源，默认窗口 OCR 不需要它。选用时需要已经能正常读取微信的兼容版本：

1. 在 WeFlow 中启用 HTTP API；实时接收还需要主动推送。
2. 填写它实际监听的本机根地址，例如 `http://127.0.0.1:5031`。
3. 配置对应 API Token。401 通常表示 Token 问题，403 可能表示推送未开启。

本应用只连接 loopback 地址；不接受远程 IP、含凭据的 URL 或重定向。不同版本的 WeFlow API 可能变化，不能仅凭健康检查成功认定消息接口也可用。

## 如何提供有用的问题报告

请附上版本、简短复现步骤、预期行为和实际行为。优先使用 `--demo` 或手写合成对话重现，并说明是否仅在某种缩放、布局或微信窗口模式下出现。

不要上传 `data/`、`credentials.json`、真实聊天、联系人、笔记或完整环境变量。安全漏洞请使用 [SECURITY.md](../SECURITY.md) 中的私下报告方式。
