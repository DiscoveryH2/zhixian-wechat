# 1.7.0 验证记录

验证日期：2026-10-04。以下结果来自 Linux 执行环境、合成聊天与本机模拟 HTTP 服务，不使用真实客户记录或外部付费模型。

## 自动回归

- 单元与契约测试：310 项，305 项通过，5 项跳过。跳过的是 Windows 原生窗口/DPAPI 和未安装 CipherTalk 的集成条件。
- QtWebChannel 桌面回归：开场、建立跟进、完成行动、归档全文检索、旧消息原文定位、外观配置，以及模型子进程生成提案、人工核对保存。验证模型提案确认前不会创建任务，保存后仍保留原文证据。
- Python 编译、三个 JavaScript 文件语法检查、发行脚本语法检查、Git 差异检查和源码/历史隐私扫描通过。
- 凭据验证：macOS Keychain 使用替身验证保存、读取和失败时拒绝落盘；Windows DPAPI 需在 Windows CI/实机验证。未验证真实 Mac 钥匙串授权弹窗。
- 媒体验证：合成 WAV 经过本机 multipart HTTP 服务，核对实际文件字段与密钥来源；既有图片/语音格式与路径边界测试通过。没有将聊天占位文本视为媒体内容。
- Mac 包审计测试核对 GnuTLS 上游公开自测向量的完整摘要，并验证其他或改动密钥仍拒绝；同时覆盖私有数据库、目录外符号链接、嵌入令牌、缺失许可证与文档；平台构建使用实际应用包自检，最终资产重新核对 SHA-256。

## 合成归档基准

命令：`python scripts/benchmark_archive.py --messages 1000000 --sessions 1000`。一次运行，1000 个会话、100 万条较短文字消息，20 次预热后查询；不包含真实媒体解码、模型调用或网络延迟。结果依赖硬件、缓存和消息长度，不代表所有客户设备的 SLA。

| 项目 | 本次结果 |
| --- | ---: |
| 导入 | 12.072 秒 |
| 初次 trigram 索引预热 | 1.954 秒 |
| 少量匹配关键词查询 P95 | 2.91 毫秒 |
| 全库匹配关键词查询 P95 | 395.48 毫秒 |
| 会话目录首屏 20 项 | 0.34 毫秒 |

每页最多返回 20 项，验证搜索命中可定位到对应原文上下文。此基准不会把完整聊天库发送给模型。

## 原生发行与剩余验证

Windows/macOS GitHub Actions 分别安装锁定依赖、运行回归、执行合成 UI 流程、打包与运行打包自检；只有两端成功才发布预览包。实际执行状态见仓库 Actions，本地 Linux 成功不代替两端构建成功。

仍需实机验收：真实微信版本兼容性、图片/语音原件、系统 TTS 声音、Mac 钥匙串授权、升级恢复、代码签名与公证。Mac 原生微信数据库和发送尚未适配。企业权限、加密聊天库和商业服务见 [商业化执行计划](COMMERCIAL_PLAN.md)。
